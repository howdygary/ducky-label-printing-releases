# Ducky Label Printing Studio downloads

This repository contains built macOS app downloads and signed update feeds only. Source code is maintained separately in a private repository.

Download the latest release, unzip it, quit the existing app, and replace it in Applications. The app requires macOS 26 or later on Apple silicon.

Updater-enabled builds check at launch and daily, verify signed downloads, and install on quit or when you choose Install and restart. Older versions require one manual upgrade to enable updates.

These personal-use builds are ad-hoc signed, not Apple-notarized. Update signatures do not bypass macOS security checks.
